## Root causes and corrections

- Four fetched FMP percentage fields were deliberately erased: ROIC/ROE/ROA from key-metrics-ttm and dividend yield from ratios-ttm. FMP's published formulas define fractional ratios. Display now retains the provider values and multiplies by100 once, without guessing from magnitude. Recorded AAPL ROE1.3718365 displays137.2%, ROIC0.5186737 displays51.9%, dividend yield0.0031766 displays0.3%.
- Forward P/E was always missing because the updated company terminal did not request annual estimates. It now uses the same estimate data type as Equity Report, through shared stable FMP transport, selecting the earliest future annual period. Positive quote / positive consensus EPS; stale-only estimates, nonfinite values, zero/negative EPS and explicit currency conflicts remain missing. Missing EPS currency/GAAP adjustment is an explicit assumption, not a certification.
- The analyst header was hardcoded Unavailable. It now receives independent estimate, price-target consensus and grade-consensus results. EPS analyst count is tied to the shown annual period; summed rating observations are never presented as unique analysts. Raw consensus target/rating observation dates remain unknown. Target upside uses a disclosed same-listing-currency assumption; explicit currency conflicts block only the calculated upside.
- Peer P/E/ROIC were erased because provider dates were absent; calculated peer ratios were erased when fiscal closes differed. They now display latest available ratios with visible per-row margin TTM dates, basis disclosure and undated-provider warnings. This does not establish an audited same-date comparison or aggregate currency amounts.
- Missing quarterly input can now use an explicitly labelled provider margin fallback. Valid quarterly calculations retain priority. Unsupported TTM revenue growth/FCF calculations remain unavailable; no annual or fabricated inputs.
- Existing stable/legacy ratio aliases and fiscal-year aliases are normalized. The lower snapshot/explicit AI evidence now retain documented key-metrics ROE/ROIC/FCF yield. Top Movers accepts both quote percentage spellings without another dispatch; a missing absolute change no longer contaminates a valid percentage with an Unavailable parenthetical.
- Profile listing currency is available as explicitly labelled metadata near quote/cap/EV values; it never silently becomes a quote-supplied or target-supplied currency.
