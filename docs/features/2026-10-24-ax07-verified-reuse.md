## Design note ? navigation and financial authorization are separate

ResearchContext remains metadata-only. The new frozen, versioned VerifiedResearchSnapshot has a run/engine/security identity, opaque session ID, session-HMAC credential scope, explicit local_earnings_sensitivity purpose, creation timestamp, bounded serialized source evidence and typed Fact-validated numerical observations, source fingerprint, validation results and HMAC integrity fingerprint. Serialized data avoids shared mutable financial objects. No session secret, raw credential, AI report, committee recommendation or raw user prompt is transferred. The public UI shows numerical provenance, not private credential/session scopes. The session-only entitlement label grants no redistribution rights.

Fresh explicit V1/V2 collection returns establish lineage; simply viewing an old run, V2 cache reuse and reopening do not. A separate private bounded session registry retains source fingerprints. Sender and recipient use AX-04 raw-quarter/saved-amount earnings reconciliation, AX-06 numerical source eligibility and existing sector-aware SavedInputs/calculation contracts. Compatible positive earnings/capitalization with explicit currency are required. Quarterly/quote/profile records must be directly identified HTTPS FMP sources; profile sector/industry must match the comparison, with retrieval within thirty days. Earnings retrieval/fiscal limits remain thirty/two hundred days. Quote retrieval is at most one day, observation at most seven days. No retrieval timestamp is reset. Complete retained original source history must still resolve uniquely and match the original binding; refreshed or edited packets require a new explicit action.

At the recipient, every render/edit validates version/purpose, session, credential scope, integrity, current source fingerprint and numerical eligibility again. Session credential changes, different companies, missing histories, staleness and tampering fail closed without deleting original research. Ticker-only action deactivates financial display while preserving retained data. No snapshot enters the existing annual per-share AI target inputs or Equity Report raw reuse bridge. Local sensitivities remain user assumptions, not forecasts/returns or advice. Host authentication, durable/user-account persistence, cross-session transfer, general verified memory and advisor integration remain open.
