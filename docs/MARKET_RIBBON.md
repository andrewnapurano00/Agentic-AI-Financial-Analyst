# Shared index ribbon

The existing ribbon on Research, Equity Report, AI Valuation, Stock Screener, Portfolio Lab and Deep Research (including V2 routing) now shows S&P500, Nasdaq Composite, Dow, Russell2000 and VIX levels and daily percentage changes. Market Brief's separate constituent ticker remains unchanged. Index levels are points, not stock prices in USD; daily changes are price changes and exclude dividends. Signs distinguish direction alongside color. All five cells remain visible in the mobile grid.

## Design note: shared quote collection

`providers/market_strip.py` collects FMP quotes with one primary batch-index request, a maximum of one legacy batch fallback, shared transport retries/timeouts, and a five-minute, credential-scoped in-memory cache. Its fixed instrument allowlist uses actual indices, without ETF substitution or quote-field stitching. Successful index rows survive partial failures. Modern `changePercentage` and legacy `changesPercentage` are percentage points; zero remains valid. Where neither is supplied, an explicit positive previousClose permits `(price / previousClose - 1) * 100`; otherwise change remains unavailable. Nonpositive/nonfinite prices and future quote timestamps are rejected. Observations arriving during retrieval are checked against response-completion time.

`ui/app_shell.py` renders the shared component and keeps up to four credential-scoped sets of prior successful quotes in session memory. A failed refresh retains each prior row with its original dates and a Saved label. No cross-credential reuse. Rows older than seven UTC calendar days or lacking an observation date carry a stale/undated badge. The caption shows provider, quote times and cache policy; per-index tooltips include exact quote/retrieval time and change formula. Missing inputs stay unavailable rather than flat. Provider errors/credentials are never rendered or saved in financial output.

Opening or rerunning a workspace can refresh the quote cache after five minutes; there is no background timer. Navigation within the TTL reuses the cache. This performs no model calls and does not regenerate saved research. FMP configuration remains in Settings. The lightweight provider is separate from the full Market Brief dashboard/history/news collection.

Primary contracts checked October18: [FMP index quote listing](https://site.financialmodelingprep.com/market-indexes), [FMP index API clarification](https://site.financialmodelingprep.com/faqs?code=data), [legacy batch quote response](https://site.financialmodelingprep.com/developer/docs/companies-batch-request-free-api). A bounded live check returned all five actual indices, with October16 observation timestamps; this establishes that check's coverage, not ongoing entitlement or guaranteed real-time data. The standalone check initially hit local certificate trust errors; enabling the same Windows truststore integration already used by the app resolved it. TLS verification was never disabled and no transport implementation was changed.
