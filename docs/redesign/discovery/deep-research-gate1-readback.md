## Active flow and data/state contract

`app.py` → `main.load_langgraph_agenticai_app` → `LoadStreamlitUI` radio route → `render_deep_research_tab` or `render_deep_research_v2_tab`. Both renderers are Streamlit fragments. V1 imports Equity Report or Screener ticker identity, builds `ResearchRequest` from the explicit `deep_research_form` submit, runs `_manager.run`, checkpoints into `dr_history`, and selects `dr_active_run`. Existing saved history is session backed and capped at five. The selected result displays evidence status, news coverage, warnings/gaps, review/finalize/retry actions, six result tabs and four downloads. V1 result tabs are keyed `dr_result_tabs_{chosen}`, rerun on change, and gate expensive tab content using `.open`.

V2 displays the selected saved header and findings before its `deep_research_v2_form`, with pilot limitations and configuration in disclosures. An explicit Run computes a request/configuration/runtime cache key; saved-result reuse selects a matching result without provider/model calls. Fresh runs checkpoint via `_save_v2` into `drv2_history` and select `drv2_active_run`; saved history is capped at eight. Selected status, saved generation caption, news coverage, warnings/gaps, legacy acknowledgement, recovery/finalization/decision controls precede six tabs and three downloads. V2 recovery uses saved evidence; its optional decision stage has separate explicit action and saved runtime/cost controls. Do not move or merge these semantics with V1.

`render_investment_brief(result, workspace, credentials)` is used by each version's sixth tab. It builds narrative excerpts and deterministic audited-earnings scenarios from saved inputs, with per-run/ticker hashed widget keys, editable Bear/Base/Bull assumptions, ineligibility/freshness reasons, provenance and JSON/CSV downloads. Its data logic and controls stay in place. The V1 source/comparison helpers retain evidence filters, selected record details, metric-audit CSV, six comparison subtabs, price trend and sector gaps. The V2 Sources/Comparison/Performance tabs retain their existing content and diagnostic counts. The 224 map rows assign each existing emission or added dynamic group to those locations.
