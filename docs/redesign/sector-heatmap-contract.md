The October 16 price correction supersedes the original Yahoo/previous-UTC-day implementation. [FMP's official historical-price-full contract](https://github.com/FinancialModelingPrep/stocks-api#stock-historical-prices) supplies the `symbol`/`historical` envelope with separate `close` and `adjClose` fields. `providers/fmp_daily_prices.py` calls `/api/v3/historical-price-full/{symbol}` using the shared FMP transport, parameters `from`/`to`, and `(5,20)` connect/read timeouts. The key is passed separately, never embedded in a stored source URL. The cached history spans ten years plus up to 800 days of warmup so daily Market Brief/company charts and sector calculations share the same per-symbol evidence. Daily charts plot **adjClose**, never substitute raw close, and have no Yahoo fallback when FMP is configured. Intraday charts retain the separate five-minute feed and its existing labeled whole-series fallback. With no FMP configuration, existing non-heatmap charts/overview can still use their labeled Yahoo path; the heatmap explicitly requires FMP.

Sector collection makes at most eleven history dispatches with three workers and one eleven-symbol quote batch; shared transport allows bounded safe retries (up to three HTTP attempts per dispatch). Both sector packets and per-symbol history cache in memory for five minutes, scoped by credential arguments. Overview sector bars/leadership and heatmap share this packet instead of using provider quote `changesPercentage`. Refresh clears the shared history and sector caches. No new model call or dependency was added.

Day uses the latest valid FMP quote timestamp/price, or explicitly labeled latest historical `close` when the quote is missing, undated, future or older. U.S. ETF quote instants map to America/New_York dates; same-day history remains eligible and cannot be used as that date's previous-close baseline. A Friday baseline can serve Monday. Missing/invalid/duplicate-date `adjClose` on the selected prior date makes Day unavailable, without jumping to an older date or substituting raw close. Daily future dates are rejected; dated missing records are retained. The quote timestamp must be aware and not later than the actual UTC instant. Currency is not inferred from absent metadata. Example: price110, previous raw close200, previous adjClose100 yields **+10%**, not -45% or an open-to-close provider change.

Week means five **observed** prior trading dates, not a certified complete exchange calendar: no missing session is filled, and dates/prices remain in the evidence disclosure. YTD uses the prior-year final observed adjusted close within seven calendar days of January1. All periods use the same latest price numerator. Partial failures preserve other sectors; old price dates remain readable with stale warnings after four calendar days. Retrieval time never establishes price freshness or completed sessions. These price/adjusted-baseline changes are not certified total returns. No Yahoo/FMP price stitching occurs in the heatmap.


Industry detail loads only on explicit request. Sector/sort/show-more controls reuse the saved screen; a credential-identity change discards the prior screen. Exact symbols are deduplicated; share classes are retained because issuer identity is not established, and no cap aggregation is made. Within each industry, ordering uses the provider market-cap field descending then ticker; currency/date are unverified. Company navigation uses the existing metadata-only ResearchContext. Sector/industry selection remains in the originating session, rather than transferring an unverified financial packet. Refresh clears sector history and screen evidence, retaining selected sector. Failed reload retains a labeled prior screen. Known credential values and standard secret forms are filtered from displayed failures.
