# Portfolio Ideas design note — 2026-10-18

The strict v1 model-output gate described below is superseded in active routing. `ranking.py` supplies four deterministic research shortlists before any model call; `workflow.py` optionally invokes `simple_ai.py`. One60-second/no-retry request returns four short pipe-separated lines (persona,3–4 supplied tickers or NONE, explanation), not a multi-field JSON object. Validate ticker membership/uniqueness and each line independently. Missing, duplicate, unknown, refused, truncated, malformed or failed AI perspectives keep their original local baskets. A successful line is labeled AI-refined; local picks stay Data-ranked and do not claim to apply free-text constraints. Local weights are1/N, and displayed facts come from source rows. Old `agent.py` remains a legacy contract only.

Local rules v1: within-sector percentile ranks for positive P/E (financials: P/B) and net margin; singleton/tied cohorts receive neutral0.5. Missing features are omitted and remaining weights normalized. Nonfinancial nonnegative debt/equity resilience is1/(1+debt/equity). Trend and pullback use clipped0.5 +/- moving-average distance/100. Warren weights quality/value/trend0.5/0.4/0.1; George value/pullback/quality0.45/0.35/0.2; Ray quality/resilience/value0.6/0.3/0.1, then greedily prefers distinct known sectors; Cathie trend/quality/sector proxy0.45/0.35/0.2. The technology/communication/health sector proxy is explicitly not proof of innovation/growth. Sector alone never qualifies a company without numerical screening data. Alphabetical tie break; fewer than three usable candidates produces an explicit empty basket. No sentiment magnitude is fabricated from news coverage.

`reuse.py` merges only credential-scoped, canonical, fresh raw quote/profile/ratio components from Equity Report and AI Valuation, retaining original timestamps. The shared canonical quote allowlist now retains priceAvg50/200. The session raw-company store is bounded at16 to retain a12-company universe; no scored-table/narrative bridge is used. Complete credential-compatible five-minute Ideas snapshots skip retrieval altogether. With all three raw company feeds available, only the shared news batch is dispatched. Missing/expired feeds use the existing bounded provider; quote402 recovery remains. Force refresh bypasses all reuse. Metadata-only Use Equity Report companies copies only a validated ticker list.

AI context is capped18,000 characters and output2,400 total completion tokens. Known GPT-5 reasoning variants (excluding pro/chat/codex) request low effort; the selected model is retained. The [official Chat Completions reference](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) specifies completion budgets include reasoning as well as visible output, so incomplete output must remain recoverable. No assertion that this was the exact prior failure: the real-data no-model probe reached the SDK boundary with12 companies and19,615 input characters, below the old38,000 cap; the prior deployed response/finish reason was not retained. No paid repro was run. Usage/status are retained when supplied, including incomplete responses. AI-off builds use zero calls. A failed AI call is not silently reclassified as an AI recommendation; all local results remain labeled. Saved inputs and AI preference survive navigation.

## User and model contracts

Enter a research prompt and4–12 tickers, then explicitly Recommend portfolios. One structured model response supplies four labeled fictional styles: Warren/value, George/contrarian, Ray/diversification, Cathie/innovation. They are perspectives from one model, not four independent agent deliberations. Cathie has no crypto-only restriction in this new flow. Each basket has3–4 unique eligible stocks or an explicit abstention. Weights are calculated locally at1/N; baskets are separate alternatives, each totaling100% before display rounding. This is not an optimizer, broker, backtest or return forecast.

`portfolio_ideas/contracts.py` owns input normalization, safe text, material fingerprints and bounded JSON export. `portfolio_ideas/agent.py` owns schemas and a single bounded call through the existing selected-model client:90-second timeout, zero retries,38,000 serialized context characters and4,500 output-token ceiling. No planning, review, debate, scraping or news-summary model calls. Unknown pricing is not zero cost or a dollar ceiling; Settings model is retained. Ticker/count/duplicate/own-company-reference checks reject invalid perspectives while preserving valid others when the overall schema parses. Entirely invalid/incomplete output preserves the prior result and freshly collected evidence. Schema checks do not independently verify the semantic accuracy of every prose claim.

## Evidence contracts and budgets

Quote-access recovery: some configured FMP plans return HTTP402 for batch-quote while regular quote succeeds. For absent batch symbols only, request one full single-company quote each through the same transport, at most12 additional logical dispatches (38 total worst case), with three workers. Keep valid batch rows intact; do not splice fields or rescue explicitly invalid/future/duplicate rows. Record the actual quote route and retrieval time per company. Report sanitized HTTP codes and precise missing/duplicate/price/time/currency exclusion reasons. Sparse coverage blocks model calls with an eligible-company count; model output errors are separate from input/evidence errors. The entry-point's bounded source-reload helper refreshes only loaded Ideas modules after source changes, preserving session results and making no provider/model calls.

`providers/portfolio_ideas.py` uses shared TLS-verified FMP transport, three workers, one quote batch, one news batch and at most profile plus ratios-ttm per company: at most26 logical dispatches at12 symbols. Safe transport retries can add HTTP attempts. Fresh credential-scoped Equity Report raw profile/ratio components may replace those individual calls via existing canonical normalization/freshness checks. No unverified scored-summary bridge is enabled. Five-minute credential/input-scoped cache; explicit force refresh clears the relevant entry. Source retrieval dates survive reuse. Ordinary reruns/downloads/navigation collect nothing and make zero models. Same explicit Generate reuses the saved result when prompt, universe, model and complete cached evidence fingerprint match; changed facts or refreshed evidence may require one call.

Eligible quotes need positive finite prices, nonfuture observation times within seven days, unique identity and compatible explicit USD quote/listing currency. Profile-only units remain an assumption; no FX conversion. TTM ratios retain zero/missing distinctions, optional period end and fractions/multiple units; future/invalid stated period dates are excluded. Technical evidence is provider SMA50/200 plus local percentage distance, with unverified provider adjustment/window policy; no invented RSI, historical returns or forecasts. Stocks with missing ratios/news retain other available evidence and explicit gaps.

News uses the [FMP stock news endpoint](https://site.financialmodelingprep.com/faqs?code=platform) with the supplied symbols and seven-day lower bound. At most80 shared articles are filtered by identity, safe credential-free links and date, deduplicated and capped at two/company. A busy symbol can crowd out others; absence is incomplete coverage, not neutral sentiment. Aware future timestamps are rejected exactly; naive publication times use disclosed UTC calendar-date filtering, with same-day timing unverified. Headline evidence does not establish causation or magnitude. No publisher scraping or outside tool access.

The UI shows concise thesis/risk/monitoring cards first; comparison/source dates, gaps, headline links and usage stay in expanders. Changes to visible controls do not rewrite saved narratives. Errors preserve prior ideas and successful data with mismatch/failure notices. CSV and bounded JSON exports retain the original evidence and usage with credential filtering. Session-backed only; no durable restore/import. Tests and browser harness use synthetic data and models with external transport blocked; PLAN records actual verification, not live investment performance claims.
